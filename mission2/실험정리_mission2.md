# Mission 2 실험 정리 (신고자 / 119대원 분류), 슬라이드 4장

---

## Slide 1. 문제 정의와 가설

**제약**: text 사용 불가, 발화 조각 단독 추론, Validation 학습 금지

**핵심 질문**: 내용 없이 1~2초 조각 하나로 누가 말했는지 알 수 있나?

**가설**: 목소리 내용보다 **녹음 환경 차이**가 더 강한 단서

| 신고자 | 119대원 |
|---|---|
| 휴대폰, 현장 소음, 급한 말투 | 상황실 헤드셋, 조용한 배경, 일정한 톤 |

→ 채널/음색을 잘 잡는 음성 표현이 필요

## Slide 2. 데이터 분석 → 설계 결정

| 확인한 것 | 결과 | 결정 |
|---|---|---|
| 통화당 발화 수 | 통화당 약 30개, 같은 두 사람 목소리 반복 | 통화당 **12개만** 뽑고 통화 수를 늘림 |
| 통화 누수 | 같은 통화가 train/dev에 섞이면 점수 부풀려짐 | **통화 단위 split** |
| 클래스 비율 | 신고자 52% | 거의 균형 → threshold **0.5 고정** |
| 발화 길이 | 중앙값 1.45초, 6초 초과 3.7% | 입력 **최대 6초** |
| 샘플레이트 | 8kHz 전화 음성 | WavLM에 맞춰 16kHz 리샘플 |

---

## Slide 3. 모델 아이디어와 해결한 문제

**모델**: WavLM 앞 4층 → 층별 평균/표준편차 → 층 가중합 → 분류기

| 고민 | 선택 | 이유 |
|---|---|---|
| 몇 층까지? | **앞 4층만** | 채널/음색은 아래층에 있음, 의미는 불필요 → 95M → 38M |
| 층을 어떻게 합칠까? | **softmax 층 가중합** | 어느 층이 유용한지 모델이 학습해서 고름 |
| 어떻게 학습할까? | **동결 → 상위 2층 미세조정** | 통계 1회 추출로 빠르게 실험, 전체 미세조정의 과적합/비용 회피 |

**실제로 부딪힌 문제**
- batch 구성에 따라 같은 발화의 예측이 달라짐 → CNN 정규화가 패딩까지 포함하는 탓 → **패딩을 발화 자기 길이로만 결정**
- 동결 분류기 과적합 (epoch 7 이후 dev loss 상승) → **early stopping**

## Slide 4. 결과와 한계

| 단계 | dev Acc | 119대원 | 신고자 |
|---|---|---|---|
| 1단계 동결 | 0.9143 | 0.857 | 0.967 |
| 미세조정 (최종) | 0.9209 | 0.876 | 0.963 |
| **Validation** | **0.9173** | 0.869 | 0.962 |

- dev ↔ Validation 차이 0.36%p → 새 통화에도 일반화
- 효율: 파라미터 38.1M, 발화당 **1.15ms**, 학습 36.8분
